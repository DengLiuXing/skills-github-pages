> [!summary]
> 用 USB 网卡（AIC8800，`wlan1`）发射 5GHz 热点，`hostapd` 管无线、`dnsmasq` 管 DHCP/DNS，`ppp0` 拨号做出口 NAT。
> 一路上的坑基本集中在两处：**NetworkManager 抢接口**和**开机时 USB 网卡还没就绪**。2026-09-06 实测 AP-ENABLED，多设备正常接入。

**环境**：树莓派 Debian，USB WiFi 网卡（AIC8800，wlan1）发热点
**上游出口**：`ppp0`（PPPoE 拨号）；**DNS 偏好**：`119.28.28.28`（DNSPod）

---

## 一、前置确认（跳过这步后面全白搭）

### 1.1 确认网卡支持 AP 模式

```bash
iw phy phy1 info | grep -A8 "Supported interface modes"
```

必须包含 `* AP`。AIC8800 实测支持：`managed / AP / AP-VLAN / monitor / mesh point / P2P-*`。

### 1.2 确认 5G 信道可用

```bash
iw phy phy1 info | grep -E "51[0-9]{2}(\.[0-9]+)? MHz" | head -6
```

### ⚠️ wlan0 和 wlan1 别搞混

- **wlan0 = 树莓派板载网卡**（MAC 与 eth0 连号，同板载 MAC 段）
- **wlan1 = USB 网卡**（AICSemi OUI，本案例用它发射）

改配置前先 `ip link` 看 MAC，别凭接口名猜。

### ⚠️ NetworkManager 是热点头号杀手

NM 会在后台反复把接口切回 managed 模式，表现为**热点起来一会儿就掉、或干脆起不来**。必须做：

```bash
sudo nmcli dev set wlan1 managed no
```

且已写入启动脚本（见第三节 0.1 步）。

## 二、配置文件

### 2.1 `/etc/hostapd/hostapd.conf`

```ini
# ================================================
# 5GHz 热点配置（hostapd）
# 能力上限：11ac / 80MHz / 单流(1x1) / 433 Mbps
# ================================================

# ---- 基础设置 ----
interface=wlan1
# ⚠️ 用 USB 网卡发射就填 wlan1

driver=nl80211
# 内核驱动接口，现代网卡通用

ssid=OpenDLX

hw_mode=a
# 频段：a = 5GHz

channel=36
# 信道 36（5180MHz），无 DFS 雷达检测
# ⚠️ 换信道时 vht/he 中心频点要同步改：36-48→42，149-161→155

country_code=CN
ieee80211d=1
# 国家码解锁国内允许的信道和发射功率

# ===== 高速核心参数 =====
ieee80211n=1
ieee80211ac=1
wmm_enabled=1
# ⚠️ WMM 绝不能设 0，11n/ac 高速传输的前提

vht_oper_chwidth=1
# 1 = 80MHz（433Mbps 上限的来源）

vht_oper_centr_freq_seg0_idx=42
# 80MHz 中心频点，必须与信道匹配

ht_capab=[HT40+][SHORT-GI-20][SHORT-GI-40]
# ⚠️ 启动报错时先删 [HT40+] 再试

vht_capab=[SHORT-GI-80]

# ---- 安全配置 ----
auth_algs=1
wpa=2
wpa_passphrase=<你的密码>
# ⚠️ 8-63 位；别用弱密码，热点是公网入口
wpa_key_mgmt=WPA-PSK
rsn_pairwise=CCMP
# AES-CCMP（WPA2 强制），不要用 TKIP

# ---- 其他 ----
ignore_broadcast_ssid=0
# 0 = 广播 SSID；1 = 隐藏（手机要手动添加网络才能连）
macaddr_acl=0

# ===== WiFi 6 (802.11ax) =====
ieee80211ax=1
he_oper_chwidth=1
he_oper_centr_freq_seg0_idx=42
he_bss_color=1
# ⚠️ 实测结论：hostapd 接受这些参数但 AIC8800 驱动 AP 模式不支持 HE，
#    beacon 里实际只有 HT+VHT，运行的是 WiFi 5。参数保留无害，见第六节。
```

### 2.2 `/etc/dnsmasq.d/hotspot.conf`

```ini
interface=wlan1
# ⚠️ 与 hostapd 一致

dhcp-range=192.168.43.2,192.168.43.20,255.255.255.0,24h
dhcp-option=3,192.168.43.1
# 网关 = 热点设备的 wlan1 IP

dhcp-option=6,119.28.28.28,223.5.5.5
# 下发给客户端的 DNS：主 DNSPod，备阿里

no-resolv
server=119.28.28.28
# dnsmasq 自身上游也走 DNSPod
# ⚠️ 不加 no-resolv 时 dnsmasq 会同时读 /etc/resolv.conf，
#    运营商 DNS 会混进上游列表（日志里能看到 192.168.198.x 之类）
```

## 三、启动脚本 `/usr/local/bin/start-hotspot.sh`

```bash
sudo tee /usr/local/bin/start-hotspot.sh > /dev/null <<'EOF'
#!/bin/bash
# ===== WiFi 热点启动脚本（USB 网卡 wlan1 版） =====

IFACE=wlan1

# ---- 0.0 等待网卡出现（开机时 USB 驱动可能还没加载完）----
for i in $(seq 1 30); do
    if ip link show "$IFACE" >/dev/null 2>&1; then
        break
    fi
    sleep 1
done
if ! ip link show "$IFACE" >/dev/null 2>&1; then
    echo "hotspot: $IFACE not found after 30s, abort" >&2
    exit 1
fi

# ---- 0. 清理旧进程（防止端口占用报错）----
pkill -x hostapd 2>/dev/null
pkill -x dnsmasq 2>/dev/null
sleep 1

# ---- 0.1 防止 NetworkManager 抢接口 / 断开已有连接 ----
nmcli dev set $IFACE managed no 2>/dev/null
iw dev $IFACE disconnect 2>/dev/null

# 关闭省电
iw dev $IFACE set power_save off 2>/dev/null

# ---- 1. 配置静态 IP ----
ip link set $IFACE up
ip addr flush dev $IFACE
ip addr add 192.168.43.1/24 dev $IFACE

# ---- 2. 开启转发 + NAT（出口 ppp0）----
sysctl -w net.ipv4.ip_forward=1
iptables -t nat -C POSTROUTING -o ppp0 -j MASQUERADE 2>/dev/null || \
iptables -t nat -A POSTROUTING -o ppp0 -j MASQUERADE
iptables -C FORWARD -i $IFACE -o ppp0 -j ACCEPT 2>/dev/null || \
iptables -A FORWARD -i $IFACE -o ppp0 -j ACCEPT
iptables -C FORWARD -i ppp0 -o $IFACE -m state --state RELATED,ESTABLISHED -j ACCEPT 2>/dev/null || \
iptables -A FORWARD -i ppp0 -o $IFACE -m state --state RELATED,ESTABLISHED -j ACCEPT

# ---- 3. 启动 dnsmasq ----
systemctl stop dnsmasq 2>/dev/null
dnsmasq -C /etc/dnsmasq.d/hotspot.conf

# ---- 4. 启动 hostapd（前台运行）----
exec hostapd /etc/hostapd/hostapd.conf
EOF

sudo chmod +x /usr/local/bin/start-hotspot.sh
```

### ⚠️ 脚本里的三处易漏点

1. **等待循环（0.0）**：开机时 USB 驱动加载可能晚于 hotspot.service，没有等待循环首次启动必失败。`exit 1` 配合 `Restart=on-failure` 自动重试。
2. **`nmcli dev set managed no`（0.1）**：不加这个，NetworkManager 会抢接口。
3. **iptables 用 `-C ... || -A` 模式**：幂等，重复执行不会堆重复规则。换网卡后旧的 `wlan0` FORWARD 规则会残留，可手动清理：
   ```bash
   sudo iptables -D FORWARD -i wlan0 -o ppp0 -j ACCEPT 2>/dev/null
   sudo iptables -D FORWARD -i ppp0 -o wlan0 -m state --state RELATED,ESTABLISHED -j ACCEPT 2>/dev/null
   ```

## 四、systemd 服务 `/etc/systemd/system/hotspot.service`

```ini
[Unit]
Description=WiFi Hotspot (hostapd + dnsmasq)
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/start-hotspot.sh
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable hotspot        # ⚠️ 忘了 enable 开机就不会起
sudo systemctl restart hotspot
```

管理命令：

```bash
sudo systemctl restart hotspot       # 改完配置后重启
sudo systemctl stop hotspot          # 关闭热点
journalctl -u hotspot -e             # 看日志排错
```

## 五、验证

```bash
journalctl -u hotspot -e --no-pager | tail -20
```

成功标志（按顺序出现）：

```
wlan1: interface state UNINITIALIZED->COUNTRY_UPDATE
wlan1: interface state COUNTRY_UPDATE->HT_SCAN
wlan1: interface state HT_SCAN->ENABLED
wlan1: AP-ENABLED
wlan1: AP-STA-CONNECTED <mac>        # 客户端接入
dnsmasq-dhcp: DHCPACK(wlan1) ...     # DHCP 分配成功
```

深入验证：

```bash
# 确认频宽（80MHz 才有 433Mbps）
iw dev wlan1 info                    # 期望: channel 36 (5180 MHz), width: 80 MHz

# 局域网真实速率（排除 WAN 干扰）
sudo apt install -y iperf3
iperf3 -s -B 192.168.43.1            # 树莓派侧
# 客户端: iperf3 -c 192.168.43.1 -P 4 -t 10
```

### ⚠️ AIC8800 驱动不实现 dump_station

`iw dev wlan1 station dump` 返回空是**驱动没实现**，不代表没有设备连接。看连接状态用 hostapd 日志，或用另一台网卡扫描：

```bash
sudo iw dev wlan0 scan freq 5180 | grep -A80 "OpenDLX" | grep -iE "SSID|HE |VHT|HT |width"
```

## 六、关于 802.11ax（WiFi 6）的实测结论

尝试：hostapd 加 `ieee80211ax=1` + `he_oper_chwidth=1` + `he_oper_centr_freq_seg0_idx=42` + `he_bss_color=1`。

结果：hostapd **接受参数无报错**，但扫描 beacon 确认只有 HT+VHT、**没有 HE IE**（`sudo iw dev wlan0 scan freq 5180`），实际运行 **WiFi 5 (ac) 80MHz 1x1**。

原因：AIC8800 驱动 AP 模式不支持 HE（`iw phy phy1 info` 的 `HE Iftypes` 段未列出 AP）。这是硬件/驱动层限制，**换配置救不了**。

### ⚠️ 峰值速率的天花板在这张卡上根本不是协议

- USB 接口是 **2.0 high-speed**（`dmesg` 显示 `high-speed`），实际吞吐上限 ~300Mbps
- 单流 1x1：ac 80MHz 理论 433Mbps，ax 也就 600Mbps
- 上游是 ppp0 拨号：宽带 < 300M 时 WiFi 侧再快也感知不到

**结论**：ac 就是这张卡的实用终点，`he_*` 配置保留无害（驱动不认等于没写）。

## 七、排错速查

| 现象 | 原因 | 处理 |
|---|---|---|
| `Could not configure driver mode` | NM 占用接口 | `nmcli dev set wlan1 managed no` |
| 起来一会儿就掉 | 同上 | 同上（写进脚本 0.1 步） |
| `Could not set channel` | 信道不支持/DFS | 换信道 149，中心频点 155 |
| `ht_capab/vht_capab` 相关报错 | 网卡不支持该能力 | 注释掉 `ht_capab`、`vht_capab` |
| 5G 起不来 | 固件限制 | 改 2.4G：`hw_mode=g`、`channel=6`，删 `ieee80211ac`/`vht_*` 三行 |
| 客户端连上但上不了网 | NAT/转发没配 | 检查 `ip_forward=1` 和 iptables 规则、`ip route` 看 ppp0 是否在 |
| 客户端拿不到 IP | dnsmasq 没起 | `dnsmasq -C /etc/dnsmasq.d/hotspot.conf` 手动跑看报错 |
| 热点开机不起 | 服务没 enable / 网卡未就绪 | `systemctl enable hotspot` + 脚本等待循环 |
| 客户端 DNS 不通 | 上游 DNS 问题 | 检查 `dhcp-option=6`，加 `no-resolv` |
