### 父 -> 子
最简单的是 prop 传参, 子组件只能读取不会传回父组件  

父组件:
``` html
<ClockDisplay
    :now="now"
    :tz="tz"
    :calibrated="calibrated"
    :offset="offset"
    :error="error"
/>
```
子组件:
``` javascript
const props = defineProps({
  now: Date,
  tz: String, 
  calibrated: Boolean, 
  offset: { type: Number, default: null },
  error: { type: String, default: null },
})
```
此时在 script 中还得用 props. 前缀读取对于数据, 但在 template 里面就可以直接使用其名称引入了

### 父 <-> 子
使用万能的 v-model

父组件:
``` html
<TimeZoneSelector v-model="tz" :disabled="isLoading" />
```

子组件:
``` javascript
const selected = defineModel('tz', { type: String }) 
const props = defineProps({ disabled: Boolean }):disabled
```

### 父 <- 子
使用 emit
父组件:
``` html
<ClockCard
  v-for="(tz, i) in tzList"
  :key="tz"
  @remove="removeTimeZone(i)" 
/> 
<!-- remove 是监听事件, 此处意思是接收到名为 remove 的 emit 后, 调用函数 removeTimeZone() -->
```

子组件:
``` javascript
// 删除按钮：通知父组件移除本卡片
const emit = defineEmits(['remove'])
```
