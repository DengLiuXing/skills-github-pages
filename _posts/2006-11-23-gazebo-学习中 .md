- 一个模型是 `<model>`，下面的其它物件都是 `<link>`, 一个物件需要有以下性质：`<inertial>`, `<pose>`, `<visual>`, `<collision>`; 他们可以使用 `<joint>` 连接起来;

- 使用插件可以引入各种功能，比如：
    - 键盘控制的功能，注意，要在 GUI 中启动  `key Publisher`
    - 传感器的功能，可以用 `gz topic -e -t /*目标*/` 来查看调试信息

  常用于查看插件信息交流的命令：
    ``` bash
    gz topic [-arg]
    ``` 

- actor 是一种视觉对象，不设置碰撞箱
- 可以使用 C++ 监听 topic 来为机器提供更加智能的算法
- 写 gzlaunch 文件，便可以使用命令来一键启动多个命令，（其实 gz 只支持 Linux，用命令行脚本或者 Python 脚本等是一样的）
