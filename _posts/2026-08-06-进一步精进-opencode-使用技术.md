  - `/compact` 用于压缩上下文  
  - opencode 根目录下可以配置 `command/*.md` 来自定义命令
    ```
    description: 描述
    agent: 属于哪个智能体
    model: 使用哪个大模型
    ```
  - opencode 根目录下可以配置 `agent/*.md` 来自定义智能体
    ```
    description: 描述
    mode: subagent 可被调用的子智能体 / primary 主智能体
    model: 使用哪个大模型
    ```
