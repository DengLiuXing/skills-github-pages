# 本周探索记录：Gazebo 深化、英语学习法与 Vue 框架初探

> [!note]
> 两周（07-27 ~ 08-09）延续了上上周 Gazebo 的学习主线，并在两条新方向上展开了探索：一是把英语学习嵌入到 Gazebo 阅读情境中，形成了可持续的单词积累方法；二是开始接触 Vue 框架，并借一次重构实战对比了不同 AI 编码组合的效果。此外，我也继续打磨了日常使用的翻译与 OpenCode 工具链。

## 1. Gazebo：从"入门"走向"会用"

上周理清了模型的基本构成，本周的重点转向让模型真正动起来、并补齐 GUI 与传感器认知：

*   **坐标与文件体系（07-27、07-29）**：掌握了 SDF 中 `<pose>` 的六元素 `x y z roll pitch yaw`，旋转方向用右手螺旋判定；引入本地模型需将模型文件夹写入环境变量。
*   **让模型动起来（07-29 补录）**：使用 `plugin` 驱动模型。接触传感器（Contact sensor）可在碰撞后把小车弹开；激光雷达（lidar sensor）能在碰撞前响应，并配合一段 C++ 程序监听/发送 `gz topic` 实现自动转弯——这也是我第一次把代码和仿真联动起来。
*   **轻量对象与 GUI（08-08 补录）**：`actor` 是无碰撞箱的可移动视觉对象，模拟开销低但不能做 collision 探测；GUI 方面，`view angle` 切三视图、`Align tool` 对齐物体、`plot 3D` 展示移动路径等插件相当实用。

> **总结**：Gazebo 已从"调通环境"推进到"能搭模型、配传感器、用 GUI"，下一步可深挖 `<world>` 的 plugin 框架与 C++ 联动程序。

## 2. 英语学习：把单词"种"在 Gazebo 语境里

本周尝试了一种新的英语学习法——在啃 Gazebo 文档/报错的同时顺手积累单词，效果出乎意料地好：

*   **积累规模**：从 07-27 到补录阶段，共整理了约 30 个词条，每条都带音标、释义、词根拆分、同根词/同义词，部分还配了 gazebo 语境例句。
*   **内容覆盖**：既有仿真术语（ground plane、localisation、axes/axis、arbitrary、attributes、caster、inertial、torque、velocity、spawning、acronym 等），也有通用词汇与短语（doodle、ward off、imposing、abbreviated、implicit、respect、preliminaries、toggle、contact、dropdown list、vertical ellipsis、wrench、fix to 等）。
*   **方法体会**：在真实项目语境里学单词，比孤立背词更有锚点，也更容易记住——这套"边用边学"的节奏打算延续下去。

> **总结**：找到了一种适合自己的英语积累节奏，且与技术学习互不挤占，值得继续发展。

## 3. AI 编码与翻译工具：打磨日常武器

*   **翻译工具排错（07-30）**：日常用 `stranslate` + 自定义大模型提示词做单词详解。排查了"输出失控"问题，根因是软件不会自动拼接原文，需在提示词中按参数方式传入 `$content`——虚惊一场的"伪 BUG"。
*   **OpenCode 进阶（08-06）**：补充了早前的命令笔记（`/init`、`/redo`、`/undo`、`/share`），并新学了 `/compact` 压缩上下文；还摸清了根目录下 `command/*.md` 自定义命令、`agent/*.md` 自定义智能体（含 description / mode / model 等字段）的配置方式。

> **总结**：工具链的认知更完整了，自定义 command / agent 的能力为后续提效留了口子。

## 4. Vue 框架：从认知到实战对比

*   **入门动机与认知（08-08）**：基于已有的 HTML/CSS/JS 经验，为做更好看方便的工具，开始浅学 Vue，定位为"AI 辅助下建立整体认知、不深究细节"。厘清了最小四件套（`package.json`、`vite.config.js`、`index.html`、`src/main.js`），以及真正改页面要动的 `App.vue` / `style.css` / `components/` / `assets/`。
*   **重构实战对比（08-09）**：用 Vue 重构一个网络请求小工具，意外成了一次 AI 编码组合的对照实验：
    *   **VS Code + CodeBuddy + DeepSeek-V4-pro**：初版 Bug 横生，多主题与全屏功能全部丢失。
    *   **opencode + Kimi-K2.7**：重构效果优秀，不仅还原原功能，还主动提出了更结构化的参数解析方案，令人惊喜。

> **总结**：opencode + Kimi-K2.7 的组合在本周任务中表现明显占优，可考虑作为主力编码助手；Vue 也顺利迈过了"从 0 到 1"的门槛。
