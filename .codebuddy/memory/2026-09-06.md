## 项目事实（树莓派 USB 网卡，备查）
- 网卡：绿联 AX900 / CM763（AICSemi AIC8800D80），USB 2.0 high-speed，单流 1x1，ac 80MHz 433Mbps 为实用上限；AP 模式不支持 HE（WiFi 6），`he_*` 配置写了也无效。
- 驱动：官方包只到 6.14，6.18 用社区 fork `goecho/aic8800_linux_drvier`；**关键坑**是 fork 精简掉了最终工作态 ID `368b:8d88`，需补三处（aic.rules / aicwf_usb.h / aicwf_usb.c）。
- 三段式初始化：`a69c:5721|5724`（U 盘，udev eject）→ `a69c:8800`（下载固件）→ `368b:8d88`（工作态，才有 wlan）。
- 接口区分：wlan0 = 板载（MAC 与 eth0 连号），wlan1 = USB 网卡（AICSemi OUI）。
- 热点：hostapd + dnsmasq，出口 ppp0 走 MASQUERADE；DNS 用 DNSPod 119.28.28.28，dnsmasq 必须加 `no-resolv`。
- 热点两大坑：NetworkManager 抢接口（需 `nmcli dev set wlan1 managed no`）、开机 USB 网卡未就绪（脚本加等待循环 + `Restart=on-failure`）。
