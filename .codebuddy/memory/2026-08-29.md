## 世界时钟项目事实要点（备查）
- 授时：`offset = 服务器时间 - Date.now()`，每 5s 重校，断网降级本地并标注"未校准"；最终用本地 mock 中间件（淘宝/timeapi.io 均因 Node 层 DNS 失败放弃）。
- 关键认知：**浏览器能通 ≠ Node 能通**；改 `vite.config.js` 必须重启 dev server（改 `src` 走 HMR 不用）。
- 时区列表用 `Intl.supportedValuesOf('timeZone')`（约 400 个，内置离线）。
- 卡片抽象层：`tzList: [{ id, type:'clock', tz }, ..., { id:'__add__', type:'add' }]` + `v-if` 类型分发，解决末位插入难题。
- 性能：rAF 直驱 DOM 绕开 Vue 响应式，避免每帧全量重渲染 + O(n²) `findIndex` + layout thrashing。
- id 用 `crypto.randomUUID()`；去重策略"删旧留新"；卡片时区改只读，入口唯一。
- 手写 MD3 样式，拒绝 vuedraggable / MDB5。
